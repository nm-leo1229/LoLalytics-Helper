# LoLalytics Helper

<img width="1918" height="1077" alt="image" src="https://github.com/user-attachments/assets/33386ad7-dac8-4e8f-bfaa-de2e04b9e555" />

리그 오브 레전드 챔피언 데이터를 LoLalytics에서 수집하고, 게임 로비에서 최적의 카운터 픽과 시너지를 추천해주는 도구입니다.

## 주요 기능

- **LCU API 연동**: 리그 클라이언트와 자동 연동하여 픽 정보 자동 감지
- **시너지 승률 표기**: 아군 챔피언과의 시너지 승률 표기 및 점수 계산
- **카운터 승률 표기**: 상대팀 챔피언에 대한 카운터 승률 표기 점수 계산
- **챔피언 추천**: 시너지와 카운터 승률을 종합하여 챔피언을 추천
- **OP 듀오 체커**: 승률 54% 이상, 픽률 2% 이상인 OP 듀오 수집

## 사용법

### 1. 로비 매니저 실행

게임 로비에서 챔피언 추천을 받으려면 `LoLalyticsHelper.exe` 혹은 `lobby_manager.py`를 실행합니다.

```bash
python lobby_manager.py
```

### 2. 기본 사용 방법

#### 2.1 나의 라인 선택

1. 상단의 "나의 라인" 섹션에서 자신이 플레이할 라인을 선택합니다
   - 탑 / 정글 / 미드 / 바텀 / 서포터 중 선택

#### 2.2 챔피언 입력

**우리팀 (왼쪽 컬럼):**
- 각 슬롯에 아군 챔피언 이름을 입력합니다
- 라인 드롭다운에서 해당 챔피언의 라인을 선택합니다
- "검색" 버튼을 클릭하거나 Enter 키를 누릅니다

**상대팀 (오른쪽 컬럼):**
- 각 슬롯에 상대팀 챔피언 이름을 입력합니다
- 라인 드롭다운에서 해당 챔피언의 라인을 선택합니다
- "검색" 버튼을 클릭하거나 Enter 키를 누릅니다

**자동완성:**
- 챔피언 이름을 입력하면 자동완성 목록이 표시됩니다
- 화살표 키(↑↓)로 선택하고 Enter로 확인할 수 있습니다

#### 2.3 추천 챔피언 확인

- 하단의 "추천 챔피언" 테이블에서 내 라인에 맞는 최적의 챔피언을 확인할 수 있습니다
- 추천은 시너지와 카운터를 합친 최종 점수 순으로 정렬됩니다

**컬럼 설명:**
- **챔피언**: 추천 챔피언 이름 (⚠ 표시는 데이터 부족 경고)
- **태그**: 
  - `카운터 N위`: 같은 라인 상대의 카운터 목록에서 픽률 1% 이상인 챔피언을 상대 승률이 낮은 순으로 세웠을 때의 순위 (추천 표에 보이는 챔피언끼리 매기며 3위까지 표시)
  - `시너지 N위`: 내 라인과 짝인 아군의 시너지 목록에서 픽률 3% 이상인 챔피언을 함께했을 때 승률이 높은 순으로 세웠을 때의 순위 (추천 표에 보이는 챔피언끼리 매기며 3위까지 표시)
    - 짝: 원딜-서포터, 서포터-원딜, 미드-정글, 탑-정글, 정글-미드와 탑 (정글은 `미드 시너지 N위`, `탑 시너지 N위`로 따로 표시)
  - `신뢰도 높음`: 모든 데이터가 2000게임 이상
  - `올카운터`: 모든 상대팀 챔피언에 대해 승률 50% 미만
  - `OP 시너지`: 아군과의 시너지 승률 55% 이상
  - `선픽 카드`는 "선픽 카드" 탭과 같은 라인별 기준을 사용합니다. 바텀은 현재 밴을 반영합니다.
  - `데이터 부족`: 최소 게임 수 기준 미달
- **최종 점수**: 시너지와 카운터를 가중치로 합친 점수 (아래 "점수 계산 알고리즘" 참고)
- **시너지**: 아군 챔피언과의 시너지 정보 (승률 표시)
- **카운터**: 상대팀 챔피언에 대한 카운터 정보 (승률 표시)

#### 2.4 필터 조정

추천 테이블 상단에서 필터를 조정할 수 있습니다:
- **최소 게임 수**: 기본값 150 (이 게임 수 이상인 데이터만 사용, 마스터 이상·최근 30일 데이터 기준)
- **최소 픽률**: 기본값 1.5 (이 픽률 이상인 데이터만 사용)
- **내 챔피언만**: 내 챔피언 탭에 넣어 둔 챔피언만 추천 (4.3 참고)
- **아군 AP 2명 이상이면 AP 제외**: 나를 뺀 아군에 AP 딜러가 2명 이상이면 추천에서 AP 딜러를 뺌 (설정은 저장됨)

나를 뺀 아군에 AP 딜러가 2명 이상이면 "우리팀" 제목 옆에 `⚠ AP 딜러 N명` 경고가 뜹니다 (마우스를 올리면 챔피언 이름 표시). AP 딜러 목록은 `ap_champions.json`에서 고칠 수 있습니다.

#### 2.5 테마 설정 (다크모드)

- 상단 우측의 "🌙" 또는 "☀️" 버튼을 클릭하여 테마를 변경할 수 있습니다.
- **다크모드**: 어두운 배경으로 눈의 피로를 줄여줍니다.
- **라이트모드**: 기존의 밝은 테마를 유지하며 가독성이 개선되었습니다.
- 설정은 자동으로 저장되어 다음 실행 시에도 유지됩니다.

### 3. LCU API 연동 (자동 픽 감지)

리그 클라이언트와 연동하여 픽 정보를 자동으로 감지할 수 있습니다.

#### 3.1 연결 점검

1. 리그 오브 레전드 클라이언트를 실행하고 로비에 들어갑니다
2. "연결" 버튼을 클릭하여 LCU 연결 상태를 점검합니다
3. 연결이 성공하면 "자동 동기화" 체크박스와 "수동 불러오기" 버튼이 활성화됩니다

#### 3.2 자동 동기화

- "자동 동기화" 체크박스를 활성화하면 픽창에서 챔피언이 선택될 때마다 자동으로 업데이트됩니다
- 2초마다 클라이언트 상태를 확인하여 변경사항을 감지합니다

#### 3.3 수동 불러오기

- "수동 불러오기" 버튼을 클릭하면 현재 픽창 상태를 즉시 불러옵니다
- 자동 동기화가 꺼져있을 때 사용할 수 있습니다

#### 3.4 스냅샷 저장

- "스냅샷 저장" 버튼을 클릭하면 현재 감지된 픽 정보를 JSON 파일로 저장합니다
- 디버깅 목적으로 `debug_data/` 폴더에 저장됩니다

**주의사항:**
- LCU 연동 기능을 사용하려면 `requests` 패키지가 설치되어 있어야 합니다
- 리그 클라이언트가 실행 중이어야 합니다
- 픽창 단계가 아니면 픽 정보를 가져올 수 없습니다

### 4. 고급 기능

#### 4.1 데이터 제외

- 각 슬롯의 "데이터 제외" 체크박스를 활성화하면 해당 챔피언의 데이터를 추천 계산에서 제외합니다
- 예: 특정 챔피언이 오프메타로 플레이되는 경우

#### 4.2 챔피언 제외 목록

- "Ignore" 탭에서 추천에서 제외할 챔피언 목록을 관리할 수 있습니다
- 추천 테이블에서 챔피언을 선택하고 "선택 챔피언 제외" 버튼을 클릭하여 추가할 수 있습니다

#### 4.3 내 챔피언만 추천

- "내 챔피언" 탭에서 라인을 고르고 챔피언 이름을 입력해 "추가"하면 라인별 내 챔피언 목록에 들어갑니다 (목록에서 골라 "선택 제거" 또는 Delete 키로 뺍니다)
- "내 챔피언만 추천" 체크박스를 켜면 추천 표에 내 라인에 넣어 둔 챔피언만 나옵니다. 챔피언 추천 탭의 "내 챔피언만" 체크박스와 같은 설정입니다. 켜 두면 추천 제외 목록보다 내 챔피언 목록이 우선합니다 (내 라인 목록이 비어 있으면 추천 표도 비어 있습니다)
- 목록과 체크 상태는 `my_champions.json`에 저장됩니다

#### 4.4 카운터/시너지 분석

- "Counter/Synergy" 탭에서 특정 챔피언의 상세한 카운터/시너지 데이터를 확인할 수 있습니다
- 라인별 필터링과 최소 게임 수 필터를 사용할 수 있습니다

#### 4.5 OP 듀오 확인

- "OP Duos" 탭에서 승률이 높은 듀오 조합을 확인할 수 있습니다
- 승률 54% 이상, 픽률 2% 이상인 조합이 자동으로 하이라이트됩니다

#### 4.6 선픽 카드

- 바텀은 글로벌 마스터+ 솔로/듀오 최근 30일 자료를 씁니다. 자력 이동기가 있는 후보 중 양 팀의 밴을 제외하고 초중반형과 후반형을 표시합니다.
  - 픽률 중앙값이 1.5%를 넘는 상대마다 양방향 승률 차이의 절반을 50%에 더하고, 양쪽 중 작은 표본을 기준으로 500판만큼 50%로 보정합니다. 이런 상대 중 한 명이라도 양방향 150판을 확보하지 못하면 후보를 보류합니다.
  - 불리한 상대부터 픽률 비중 20%를 채운 가중 평균이 49% 이상이어야 합니다. 시간대별로 바텀 전체 표본의 승률과 비교하고 500판만큼 해당 구간 평균으로 보정합니다. 15–25분과 30–40분을 각각 두 개의 5분 구간에 같은 비중을 주어 계산합니다.
  - 두 시간대 중 평균을 웃도는 폭이 더 큰 쪽으로 분류하고 유형 안에서 그 폭이 큰 순으로 정렬합니다. 이 수치는 **해당 시간에 끝난 경기**의 승률 차이입니다.
- 탑·정글·미드·서포터에서는 가장 불리한 상대 하나를 밴한 뒤 남은 상대 중 최저 보정 승률이 높은 순서로 보여 주고, 49% 이상이면 ★를 표시합니다.
- 추천 제외 목록의 챔피언도 그대로 보여줍니다

#### 4.7 통계 분석

- 탑·미드·바텀·서포터 칸에서 **초중반형 선픽**과 **후반형 선픽**을 한 명씩 확인할 수 있습니다. 15–25분과 30–40분에 끝난 경기의 승률을 각각 같은 라인·시간대 평균과 비교합니다. 정글은 종합 밴픽 설계를 보여 줍니다.
- 탑·미드·서포터는 해당 라인에서 수집한 모든 챔피언(픽률 0.5% 이상)을 평가합니다. 바텀에는 자력 이동기 조건도 적용합니다. 유형별 선픽은 불리한 상성 평균 49%를 통과하고 해당 시간대 성적이 라인 평균을 웃도는 후보 중에서 고릅니다. 유형별 후보가 없으면 그대로 표시합니다.
- 유형별 선픽마다 **추천 밴**을 함께 보여 줍니다. 그 선픽을 할 때 하나 더 밴하면 불리한 상성 평균이 가장 오르는 상대이고, 화살표 뒤는 그렇게 밴했을 때의 평균입니다.
- 하단의 **유형별 선픽에 추가할 밴**으로 픽창 밖에서도 밴 효과를 비교할 수 있습니다. 화살표는 밴이 없을 때와 적용했을 때의 불리한 상성 평균을 표시합니다. **없음**으로 되돌리면 현재 픽창 밴만 적용합니다.
- 각 칸의 **종합 설계**에서는 다음 항목을 확인할 수 있습니다. 종합 선픽·대안 옆의 시간대 표시는 그 챔피언의 경기 종료 시간대별 성향입니다.
  - 선픽: 가장 불리한 상대 하나를 밴한 뒤 남은 최저 승률이 가장 높은 챔피언 (추천 제외 목록은 뺌). 바로 아래 줄은 밴 뒤에 가장 불리한 상대
  - 대안: 선픽 다음으로 점수가 높은 챔피언 (선픽이 밴되거나 뺏겼을 때)
  - 밴: 이 설계의 선픽이 가장 불리한 상대
  - AD 선픽·AP 선픽 (탑·정글·미드·바텀): 아군 조합이 올 AD나 3 AP로 쏠리지 않게 고를 종류별 선픽 1위. AP는 `ap_champions.json`의 챔피언, AD는 그 밖의 챔피언입니다
  - 후픽: 준비해 두면 전체 승률이 0.05%p 이상 오르는 챔피언 (최대 3개). 들여 쓴 줄은 그 챔피언이 보이면 선픽 대신 꺼낸다는 뜻
- 숫자는 부풀림을 빼고(아래 "승률의 부풀림 보정" 참고) 표본이 적은 상성을 평균 쪽으로 당긴 승률입니다
- 바텀과 서포터는 2대2라 상대 짝과의 상성, 아군 짝과의 시너지까지 넣어 계산합니다. 다른 라인은 맞라인만 봅니다
- 후보는 추천 제외 목록에 없고 그 라인 픽 점유율이 1% 이상인 챔피언입니다. 추천 제외 목록을 바꾸면 다시 실행해야 반영됩니다
- 앱 없이 `python banpick_stats.py` 로도 라인별 밴픽 설계를 출력합니다. 기준값(후보 픽 점유율, 후픽 기준 등)은 그 파일 맨 위에서 고칩니다

### 5. 데이터 수집 (최초 1회 또는 업데이트 시) (배포자용)

데이터를 수집하려면 `scraper.py`를 실행합니다.

```bash
python scraper.py
```

**주의사항:**
- Chrome 브라우저가 설치되어 있어야 합니다
- 수집 대상은 실행할 때마다 LoLalytics 티어 목록에서 자동으로 정합니다 (레인별 픽률 0.5% 이상인 챔피언)
- 수집 대상과 데이터 모두 최근 30일, 마스터 이상 구간 기준입니다
- 수집 중 Chrome 창은 다른 창으로 가려 두어도 되지만 최소화하지는 마세요 (최소화하면 느려지고 일부만 수집될 수 있습니다)
- 수집에는 시간이 오래 걸릴 수 있습니다 (모든 챔피언 기준 수 시간)
- 수집된 데이터는 `data/` 폴더에 JSON 파일로 저장됩니다. 업데이트 시에는 모든 json 파일을 제거하고 다시 파일이 생성 될 수 있도록 해주세요

## 문제 해결

### 스크래퍼가 작동하지 않을 때

- Chrome 브라우저가 설치되어 있으면 undetected-chromedriver가 해당 버전에 맞는 드라이버를 자동으로 사용합니다
- 인터넷 연결을 확인하세요
- LoLalytics 웹사이트가 접근 가능한지 확인하세요

### LCU 연결이 안 될 때

- 리그 클라이언트가 실행 중인지 확인하세요
- 픽창 단계에 들어가 있는지 확인하세요
- `requests` 패키지가 설치되어 있는지 확인하세요
- "연결" 버튼을 클릭하여 연결 상태를 점검하세요

### 추천이 표시되지 않을 때

- "나의 라인"이 선택되어 있는지 확인하세요
- 우리팀 또는 상대팀에 최소 1명의 챔피언이 입력되어 있는지 확인하세요
- `data/` 폴더에 해당 챔피언의 데이터 파일이 있는지 확인하세요

## 점수 계산 알고리즘

### 기본 점수 계산

- **시너지 점수**: 아군 챔피언과의 승률을 기반으로 계산
- **카운터 점수**: 상대팀 챔피언에 대한 승률을 100에서 뺀 값 (승률이 낮을수록 높은 카운터 점수)
- **시너지 점수 / 카운터 점수**: 각 승률에 라인 가중치를 곱해 더한 뒤 가중치 합으로 나눈 평균
- **최종 점수**: 2 × (시너지 가중합 + 카운터 가중합) / (시너지 가중치 합 + 카운터 가중치 합). 한쪽만 있으면 그 점수 그대로

### 승률의 부풀림 보정

수집한 승률은 마스터 이상 필터 때문에 같은 대결을 양쪽에서 본 두 승률의 합이 100%가 아니라 약 105%입니다 (그 챔피언을 잡은 사람이 마스터 이상인 판만 세기 때문). 앱은 표(라인 조합)마다 이 부풀림의 평균(약 2.5%p)을 데이터에서 계산해, 화면에 보이는 승률과 점수 계산에 쓰는 승률에서 뺍니다. 그래서 앱의 승률은 LoLalytics 사이트의 숫자보다 약 2.5%p 낮고, `올카운터`(50%), `OP 시너지`(55%), OP 조합(54%) 같은 기준도 보정한 승률에 적용됩니다.

### 라인 가중치

각 라인 조합에 따라 가중치가 적용됩니다:
- 동일 라인 대결: 가장 높은 가중치 1.0 (예: 미드 vs 미드)
- 관련 라인: 중간 가중치 (예: 정글 vs 미드, 원딜 vs 상대 서포터)
- 비관련 라인: 낮은 가중치 (예: 탑 vs 바텀)

기본값은 수집 데이터에서 라인 조합별로 상성 고유 효과의 크기(챔피언 자체의 강함과 표본 잡음을 뺀 값)와 표본 수를 재서 정했습니다. 맞라인 카운터가 1.0으로 가장 크고, 시너지는 카운터보다 낮게(원딜-서포터 0.5가 최대) 잡아 최종 점수에 카운터가 더 크게 반영됩니다.

가중치는 "가중치 설정" 탭에서 사용자가 직접 수정할 수 있습니다.

### 평균 회귀 (데이터 부족 보정)

데이터가 부족한 슬롯에 의한 점수 왜곡을 방지합니다:
- 등록된 챔피언 중 데이터가 없는 슬롯에 대해 **중립 점수(50점) × 라인가중치** 적용
- 예: 상대팀 5명 중 2명만 데이터가 있으면, 나머지 3명은 50점으로 계산
- 이를 통해 단일 데이터에 의한 과도한 점수 편향을 방지

### Ignore List (제외 목록)

- **추천 목록 제외**: 제외된 챔피언은 추천 챔피언 목록에 표시되지 않음
- **점수 계산 포함**: 제외된 챔피언도 시너지/카운터 점수 계산에는 포함됨
